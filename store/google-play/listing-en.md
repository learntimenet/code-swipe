## Full description (max 4000)
Does it run or does it crash?

Code Swipe turns reading code into a fast swipe game. Each card shows a short Python or JavaScript snippet. Swipe right if you think it runs, swipe left if you spot the bug.

After every answer, a short explanation shows you why: a missing parenthesis, a reassigned const, a forgotten colon… the classic mistakes every developer makes.

GAME MODES
• Sprint: answer as many cards as you can in 60 seconds
• Survival: 3 lives, not one more
• Daily challenge: 10 cards, 2x XP

WHY CODE SWIPE
• Train your eye to catch bugs before you run the code
• Bite-sized sessions, perfect for a break or the commute
• Clear explanations after every card
• Available in English and French

Ideal for students, beginners, and developers who want to sharpen their code-reading reflexes.
