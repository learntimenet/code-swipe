# Fiche Google Play — Français (fr-FR)

## Nom de l'application (30 max)
Code Swipe

## Description courte (80 max)
Glisse à droite si le code marche, à gauche s'il plante. Python et JavaScript.

## Description complète (4000 max)
Ça marche ou ça plante ?

Code Swipe transforme la lecture de code en jeu de swipe rapide. Chaque carte affiche un court extrait de code Python ou JavaScript. Glisse à droite si tu penses qu'il fonctionne, à gauche si tu repères le bug.

Après chaque réponse, une explication courte te montre pourquoi : parenthèse oubliée, constante réassignée, deux-points manquant… les erreurs classiques que tout développeur fait.

MODES DE JEU
• Sprint : un maximum de cartes en 60 secondes
• Survie : 3 vies, pas une de plus
• Défi du jour : 10 cartes, XP x2

POURQUOI CODE SWIPE
• Entraîne ton œil à repérer les bugs avant d'exécuter le code
• Des sessions courtes, parfaites pour une pause ou les transports
• Une explication claire après chaque carte
• Disponible en français et en anglais

Idéal pour les étudiants, les débutants et les développeurs qui veulent aiguiser leurs réflexes de lecture de code.
